Short Reflection:
1. I created four functions, addition, subtraction, multiplication, and division.

2. Every function have two parameters, num1 and num2.

3. The arguments passed into the functions were the variables num1 and num2. These hold the
   decimal values entered by the user through the input(), and float().

4. The program used the returned value by passing it into the print() function. This displayed
   the final answer of the calculation for the user to see.

5. Dividing the program into functions makes the code easier to read, and much simpler to debug.
   If a math formula is wrong, I can fix it inside that function instead of searching through the
   whole entire code. It also makes the code reusable, if I want to use the addition again, I can
   just add add() again without rewriting it manually.
